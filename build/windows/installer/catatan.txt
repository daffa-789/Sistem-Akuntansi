FINOVA - CATATAN PENGGUNAAN (versi terpasang)
==============================================

Menjalankan aplikasi
  Klik pintasan "Finova" (Menu Mulai atau Desktop). Aplikasi terbuka sebagai
  JENDELA SENDIRI - bukan tab peramban. Finova tidak memakai port tetap: setiap
  kali jalan ia meminta port bebas kepada Windows, jadi tidak akan bertabrakan
  dengan aplikasi lain di komputer Anda.

  Bila Anda memang memerlukan port tertentu (mis. untuk dibookmark):

      "%LOCALAPPDATA%\Programs\Finova\finova.exe" -app -port 5201

Berhenti / mulai ulang
  Tutup jendela Finova - prosesnya ikut berhenti dan portnya dilepas.

  Klik pintasan lagi saat aplikasi masih terbuka: jendela yang sudah ada yang
  dimunculkan ke depan, bukan server kedua.

  Hanya bila jendela membeku dan tidak bisa ditutup:

      taskkill /IM finova.exe /F

Jalur peramban (opsional, untuk pemeriksaan)
      finova.exe -browser         tampilkan di peramban default, bukan di jendela
      finova.exe -no-browser      jalankan tanpa membuka apa pun (hanya server)

Letak data
  Seluruh pembukuan disimpan pada satu berkas SQLite:

      %APPDATA%\Finova\finova.sqlite        (mis. C:\Users\NamaAnda\AppData\Roaming\Finova)
      %APPDATA%\Finova\finova.sqlite-wal    (catatan write-ahead, biarkan bersama)
      %APPDATA%\Finova\finova.log           (log saat berjalan tanpa konsol)
      %APPDATA%\Finova\webview2\            (profil tampilan; boleh dihapus bila bermasalah)

  Salin berkas .sqlite tersebut untuk cadangan. Menyalinnya ke komputer lain yang
  sudah terpasang Finova akan memindahkan seluruh jurnal, bagan akun, dan jejak audit.

Pindah data ke tempat lain
  Jalankan dengan parameter -db, contoh:

      finova.exe -app -db "D:\Akuntansi\kantor.sqlite"

Perintah baris
      finova.exe version              tampilkan versi
      finova.exe db:init              buat/perbaiki struktur basis data lalu keluar
      finova.exe db:clean             kosongkan transaksi, bagan akun tetap tersimpan
      finova.exe -h                   daftar parameter

Mengubah nama perusahaan atau operator
  Buat berkas .env di folder data (%APPDATA%\Finova) berisi, misalnya:

      COMPANY_NAME=CV Maju Bersama
      OPERATOR_NAME=Budi
      PORT=5201        (kosongkan saja bila tidak perlu port tertentu)

  Berkas .env di folder kerja aplikasi juga dibaca; nilai dari baris perintah
  (-port, -db) lebih utama daripada isi .env.

Melepas
  Hapus lewat "Tambah atau hapus program" di Pengaturan Windows, atau jalankan
  "%LOCALAPPDATA%\Programs\Finova\uninstall.exe". Saat melepas, Anda akan ditanya
  apakah data pembukuan ikut dihapus - pilih Tidak untuk menyimpannya.
